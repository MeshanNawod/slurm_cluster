What each script still asks

node-setup.sh   (each worker)  : node name (e.g. node3)
head-setup.sh   (head)         : password
slurm-setup.sh  (head)         : password

Order: node-setup.sh on every node -> head-setup.sh -> create slurm.conf -> slurm-setup.sh

node-setup.sh also turns off automatic updates on each worker.
